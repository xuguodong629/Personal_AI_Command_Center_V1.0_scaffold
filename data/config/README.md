# data/config · 配置与密钥

**用途**：界面「设置」写入的参数与密钥都落在这里（JSON，纯文本）。

| 文件 | 内容 | 敏感 |
|---|---|---|
| `ai.json` | 模型供应商（名称/Base URL/API Key/模型 ID）与默认模型 | 🔴 高 |
| `search.json` | 搜索引擎（Tavily / 智谱）Key、时间范围、每路结果数、限定与排除域名、排除词、抓取器、单次抓取页数、跳过登录墙、备用引擎 | 🔴 高 |
| `voice.json` | 面试官音色、语速、识别模型、设备与精度 | 低 |
| `mcp.json` | MCP 服务器（stdio 命令 / http 地址 / env） | 🟠 中高 |
| `contact.json` | 付费工商数据源预留位（未启用） | 🔴 高 |

**约定**
- **只用界面改**（左下角 ⚙ / `Ctrl+,`），不要手改；手改后需保证 JSON 合法。
- 改完**即时生效**；只有改 Python 代码才需要重启后端。
- **切勿外传**：对外分享项目前先清空本目录（`data/` 已在 `.gitignore` 中，默认不会提交）。
- 备份/换机时本目录单独加密保存。
