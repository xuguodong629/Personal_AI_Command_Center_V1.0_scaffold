# data/models · 本地模型缓存

**用途**：存放语音识别（faster-whisper）等本地模型权重，**放在项目内**以保证可迁移、不污染系统目录。

**说明**
- 首次使用语音识别时自动下载，默认走 hf-mirror 镜像；大小随模型等级增长（base < small < medium < large-v3）。
- 已设置 `HF_HOME` 指向项目内、并关闭 Xet 传输（规避系统盘权限问题）。
- **可随时删除**：删掉后下次使用会重新下载，不影响任何业务数据与配置。
- 体积通常最大（数百 MB ~ GB 级），备份时可按需排除。

**相关**：识别模型等级在「设置 → 语音参数」里切换；等级越高越准、越慢（medium 约 2× 实时耗时）。
