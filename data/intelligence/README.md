# data/intelligence · 情报与背调

**用途**：**针对具体对象**的情报产物——公司背调报告、行业简报、触点地图、风险标记。

**组织方式**：`<公司名>/<YYYY-MM-DD>-背调.md`；行业简报可放 `_行业/<主题>/...`。

**约定**
- 每条关键信息标注**来源链接**与**可信度**（已证实 / 待核实 / 传闻）。
- 背调结果请保留「存疑与待核实」小节，不要把推测写成事实。
- 玩法与筛选逻辑见 `docs/模块/02-公司背调.md`。
- **合规**：只用公开信息与授权数据源；不抓登录墙平台、不采集个人信息。
- 生成后的报告在界面「公司背调」中可直接下载，下载件按同一命名归档到这里。
