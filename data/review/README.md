# data/review · 复盘

**用途**：周期性回看——日/周/月复盘、面试复盘、模块与方法使用复盘。

**命名建议**
- 周复盘：`2025-W11-复盘.md`
- 月复盘：`2025-03-月复盘.md`
- 面试复盘（单场）：`2025-03-25-A公司二面-复盘.md`

**推荐结构**

```markdown
## 本周事实（做了什么、结果如何，只写可验证的）
## 数据（投递数 / 回复率 / 面试数 / 通过率）
## 判断错在哪 / 对在哪
## 下周只改一件事
```

**约定**
- 与 `../decisions/` 联动：到了复盘日期就回填决策的复盘结论。
- 面试复盘可与界面「模拟面试」的 AI 点评互相印证，但**以真实面试结果为准**。
- 复盘结论若上升为通用认知，请提炼进 `../knowledge/`。
