# data/knowledge · 长期知识库

**用途**：沉淀**可复用**的认知与方法——行业逻辑、岗位方法论、谈判话术、模板、清单、读书笔记。

**组织方式**：`<主题>/<文档>.md`（例：`渠道管理/经销商谈判要点.md`）

**已用目录**
- `_行业/<行业名>/`：**行业赛道研判报告**（由「行业赛道」模块自动归档，front-matter 含档位与分数，可按时间对比档位迁移）

**约定**
- 只放"下次还能用"的内容；一次性的东西留在 `../inbox/` 或 `../intelligence/`。
- 每篇建议包含：结论在前、依据在后、适用条件、失效条件。
- 由「AI 助手」整理、由「技能」复用；可挂 Git MCP 服务器做版本管理。
- 与个人画像相关的偏好/底线请放 `frontend/public/config/local-defaults.json`，不放这里。
