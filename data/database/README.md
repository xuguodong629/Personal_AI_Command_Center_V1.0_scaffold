# data/database · 结构化数据

**用途**：需要**筛选、排序、统计**的表格型数据。文件形态 CSV / JSON / SQLite 均可。

**典型内容**
- `jobs.csv` 岗位库：公司、岗位、城市、薪资区间、来源链接、投递日期、状态
- `companies.json` 公司库：名称、行业、规模、融资阶段、背调结论、优先级
- `contacts.csv` 联系人库：**角色与公开联系方式**（公司邮箱/官方渠道）、所在公司、沟通节点
- `tracker.sqlite` 需要联表查询时的 SQLite 库（可配 SQLite MCP 服务器直接查）

**约定**
- 列名用英文小写下划线（`company_name`、`salary_min`…），便于程序与模型稳定解析。
- 每份表建议配一个同名 `.md` 说明字段含义与更新方式。
- **合规红线**：不收录个人手机号等个人敏感信息；只保留公开渠道与角色信息。
- 由 AI 助手或技能生成的内容，落盘前先确认字段是否符合本约定。
