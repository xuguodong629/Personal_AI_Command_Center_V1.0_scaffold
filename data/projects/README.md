# data/projects · 项目 / 求职进程

**用途**：**一个机会一个目录**，把这条线的全部材料放在一起，形成完整时间线。

**组织方式**：`<公司>-<岗位>/`，目录内建议：

```
<公司>-<岗位>/
├─ 00-概览.md          目标、当前阶段、下一步、联系人（不含个人手机号）
├─ 01-JD.md            原始 JD + 拆解结果
├─ 02-背调.md          引用 ../intelligence/ 的结论
├─ 03-简历-v1.md       针对该岗位的简历版本（版本递增，不覆盖）
├─ 04-面试记录.md      逐轮记录（可链接 data/interview/<id>.json）
└─ 05-进展日志.md      每次沟通的时间、对象角色、结论
```

**约定**
- 不同岗位的简历**分版本保存**，便于复盘哪种表述更有效。
- 阶段建议：`接触 → 初筛 → 面试 → 终面 → 谈薪 → 结果`。
- 关键岔路口的选择同步记到 `../decisions/`。
