# data/interview · 模拟面试工作区

**用途**：一次面试 = 一个 JSON 文件，保存题目计划、逐轮问答、语音识别文本与 AI 点评。

**文件**：`<id>.json`

```jsonc
{
  "id": "…",
  "title": "某公司-渠道经理-第1轮",   // 可重命名
  "company": "…", "position": "…",
  "tags": ["…"],                        // 支持手动 + 自动建议标签
  "mode": "text | voice | live",        // 文字 / 语音单轮 / 连续对话
  "created_at": "…", "updated_at": "…",
  "turns": [ { "role": "interviewer | me", "text": "…", "at": "…" } ],
  "review": { }                         // 结构化点评与复盘
}
```

**约定**
- 界面支持：新建/清空、工作区列表、分类与标签检索、重命名、折叠/展开、删除。
- 题目结构按 12 题计划推进（1 开场 / 4 专业 / 4 行为 / 2 反问 / 1 收尾）。
- 语音模式：**边说边显示**识别文字，结束后可选择听面试官提问（edge-tts 播报）。
- 想清理历史：界面删除或直接删文件，互不影响。
- **合规**：这里存的是你的自述内容与模拟问答，不要粘贴前雇主保密材料或他人隐私信息。
