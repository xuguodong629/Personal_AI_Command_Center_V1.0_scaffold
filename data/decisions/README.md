# data/decisions · 决策记录

**用途**：记录**关键选择**及其依据，让半年后的自己能复盘"当时为什么这么选"。

**命名建议**：`YYYY-MM-DD-<决策主题>.md`（例：`2025-03-20-是否接受A公司降薪offer.md`）

**推荐结构**

```markdown
# 决策：<主题>
- 日期 / 决策人 / 状态（已定 / 待定）
## 背景
## 选项（含各自代价）
## 判断依据（画像 · 优先级 · 底线 · 8 维权重）
## 结论与生效条件
## 复盘日期与复盘结论
```

**约定**
- 依据要对齐个人画像与底线（`frontend/public/config/local-defaults.json`），而不是"感觉"。
- 结论要写**生效条件**（例如"若通勤 >90 分钟则重新评估"），便于触发复查。
- 到期后在 `../review/` 写复盘，并回填本文件的复盘小节。
