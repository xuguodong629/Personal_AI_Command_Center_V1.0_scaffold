> 入口：左下角 ⚙ 或 `Ctrl+,` ｜ 前端 `SettingsModal.tsx`、`ModelsSettings.tsx` ｜ 后端 `app/ai.py`、`app/voice.py`

## 一、设置页结构

| 标签页 | 内容 | 落盘位置 |
|---|---|---|
| **模型直连（推荐）** | 供应商增删改（预设：智谱 GLM / DeepSeek / Ollama / Kimi / 通义 Qwen / 自定义）、逐个「测试连接」、选择默认模型 | `data/config/ai.json` |
| **Dify 工作流（可选）** | 旧引擎：Dify 地址 + 三个工作流 Key（岗位雷达 / 公司背调 / AI 猎头中枢）；各模块顶部可切回 | 浏览器 localStorage |
| **搜索引擎** | **免 Key**：DuckDuckGo（ddg，实测国内可用）/ 自建 SearXNG / 任意 MCP 检索工具；**需 Key**：Tavily / 智谱 / Serper / Brave / 博查 + **「测试检索」自检**、时间范围、每路结果数（3–20）、限定/排除域名、排除词（只作提示词指令）、正文抓取器、单次抓取页数（0–16）、跳过登录墙、备用引擎 | `data/config/search.json` |
| **语音参数** | 面试官音色（3 男声 2 女声）、语速 6 档、识别模型（base/small/medium/large-v3）、设备与精度 | `data/config/voice.json` |

## 二、模型路由约定（当前实现）

| 场景 | 建议用谁 | 理由 |
|---|---|---|
| 批量轻任务（技能试运行、简单问答） | 本地 Ollama Qwen3.5-4B | 免费、隐私、离线 |
| 面试点评 / 复盘报告 / 深度分析 | DeepSeek（`deepseek-flash` 起） | 质量与成本平衡 |
| 备用 | 智谱 GLM | 主引擎不可用时的兜底（搜索同理，可配置备用引擎） |

> ⚠️ **DeepSeek 只能当"模型"，不能当"检索"**（实测结论，见下）：
>
> | 探测 | 结果 |
> |---|---|
> | `POST /chat/completions` + `tools=[{"type":"web_search"}]` | **HTTP 422**：`unknown variant web_search, expected function`（只接受自定义 function 工具） |
> | `POST /responses` + 同款内置工具 | HTTP 200，但**无 `web_search_call`、无任何 URL**；模型自己回答"我无法直接实时浏览" |
> | `POST /web_search` / `/search` / `/v1/web_search` | **全部 404**（没有独立搜索端点） |
> | 官方文档 Tools 表 | `web_search / file_search / code_interpreter / computer_use / mcp` 内置工具 → **忽略** |
>
> 结论：DeepSeek 网页版/App 的联网搜索**不对外开 API**。所以「模型用 DeepSeek + 检索另配引擎」是唯一正确组合；
> 若暂时没有可用搜索额度，用雷达/背调的「手工粘贴材料」模式（把 DeepSeek App 搜到的内容粘进来）即可零成本出报告。
> 复核脚本：`backend/probe_deepseek_search.py`、`backend/diagnose_search.py`。

> 界面按**模块**记住所选模型（`jc-chat-provider` 等）；切换模型即刻生效，无需重启。
> 「按用途绑定模型」（面试用强模型、分类用便宜模型）是规划项，可显著降本。

## 三、双引擎设计

```
每次业务请求携带 provider_id
      ↓ 后端 _load_providers() 读 data/config/ai.json
      ↓ _llm_call / _llm_call_tools → OpenAI 兼容 chat/completions
      ↓ 统一错误翻译（402 余额 / 401 鉴权 / 404 地址 / 429 限流）→ 前端显示可读原因
```

## 三之二、检索引擎实测可用性（本机网络，2026-09 实测）

| 引擎 | 需要 Key | 实测结果 | 结论 |
|---|---|---|---|
| **ddg（DuckDuckGo, 通过 `ddgs` 包）** | ❌ 免 Key | ✅ **5 条 / 2.1 秒**，直接召回猎聘、BOSS直聘岗位页 | **首选**：零成本零注册，中国岗位也能搜到 |
| Tavily | ✔ | HTTP 432 额度用尽（免费 1000 次/月，可等重置） | 额度耗尽时切 ddg |
| 智谱 | ✔ | HTTP 429 余额不足 | 需充值 |
| Serper | ✔ | HTTP 403（**网络可达**，注册即可用，免费 2500 次一次性） | 备选 |
| 博查 Bocha | ✔ | HTTP 404（**网络可达**，按量计费、国内直连） | 备选 |
| Brave | ✔ | ❌ **连接超时（被墙）** | 不要注册，除非有代理 |
| SearXNG 公共实例 | ❌ | ❌ searx.be / priv.au 等**全部超时** | 只能自建（Docker） |
| MCP 检索工具 | 取决于工具 | 支持把任意 MCP 工具接成引擎（`engine=mcp` + server/tool/参数名） | 见下节 MCP 清单 |

> 复核命令：`backend/.venv/Scripts/python.exe backend/probe_free_search.py`（一键测 ddg、SearXNG 实例、各付费端点可达性）

## 三之三、MCP 选型建议（与"能不能帮上检索"直接相关）

关键前提：**MCP 工具默认只被「AI 助手」调用**；要让雷达/背调也用上，需要把工具接成搜索引擎（设置 → 搜索引擎选 `MCP 检索工具`，填服务器 id + 工具名 + 查询参数名）。

| 用途 | 推荐 MCP | 说明 | 对本项目的价值 |
|---|---|---|---|
| 免 Key 网页检索 | **SearXNG 类**：[mcp-server-freesearch](https://github.com/wzj177/mcp-server-freesearch)、[agent-search](https://github.com/brcrusoe72/agent-search)（自带 SearXNG，一条命令部署） | 需要自建实例（公共实例本机不可达） | ⭐⭐⭐ 自建后可当引擎用，完全免费可控 |
| 免 Key 检索（轻量） | [duckduckgo-mcp](https://pypi.org/project/duckduckgo-mcp/)、[duckduckgo-mcp-agent](https://github.com/cploutarchou/duckduckgo-mcp-agent) | 免 Key；但 **ddg 已内建**，多数情况不必再装 MCP | ⭐ 重复能力，可跳过 |
| 招聘数据 | [jobspy-mcp-server](https://github.com/chinpeerapat/jobspy-mcp-server)（基于 python-jobspy） | 覆盖 LinkedIn / Indeed / Glassdoor / Google Jobs；**不含 BOSS/智联/猎聘**，且境外站点需代理 | ⭐ 只对外企/海外岗位有用 |
| 上市公司财务 | [akshare-one-mcp](https://pypi.org/project/akshare-one-mcp/)、[china-stock-mcp](https://pypi.org/project/china-stock-mcp/) | A股/港股行情与财报（akshare 生态） | ⭐⭐ 做**上市公司背调**（营收、毛利、现金流）很实用 |
| 文件/知识库 | 官方 `server-filesystem`、`server-fetch`、`server-sqlite`、`server-memory`、`server-sequential-thinking` | 扩展中心已内置这些预设 | ⭐⭐ 报告落盘、知识库检索、结构化推理 |
| 工商/司法（国内） | ⚠️ 没有成熟开源 MCP | 企查查/天眼查只有付费 API；公示系统、裁判文书网以人工网页为准 | 用「手工粘贴材料」把查到的内容喂进来 |

**不建议装**：任何声称"绕过登录墙/验证码""批量导出招聘平台简历/手机号"的 MCP——违反平台条款与《个人信息保护法》，
本项目也一律不采集个人手机号（合规红线见 README）。

- 记忆：`/api/providers`、`/api/providers/test`、`/api/ai/chat`、`/api/ai/chat-tools`
- 全部走 OpenAI 兼容协议，因此**换模型不改代码**（DeepSeek / GLM / Qwen / Kimi / Ollama / 任何兼容服务）

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 状态卡显示「后端未启动 :8787」 | 后端没起来；用 `启动.bat` 或重启桌面窗口（桌面壳会自动拉起） |
| 改了配置不生效 | 配置即时生效；**改了 Python 代码**才必须重启后端 |
| 检索一直「无结果」 | 看结果顶部「检索诊断」：多为 Key 填错（Tavily 需 `tvly-` 开头）或余额/限流 |
| 出现 503 | 常见于系统代理劫持 localhost：把 `127.0.0.1` 加入代理例外 |
| 端口 8787 被占用 | 旧后端没退：双击 `停止.bat`（或任务管理器结束对应 python）后重启 |
