# 模块 02 · 公司背调（VC 尽调 + 风控体检）

> 入口：侧边栏「公司背调」/ `Ctrl+2` ｜ 前端 `frontend/src/views/BackgroundView.tsx`、`components/RiskPanel.tsx` ｜ 后端 `backend/app/ai.py`、`risk.py`、`archive.py`

## 一、三层架构（先确定性、后模型）

```
① 规则层  backend/app/risk.py       手填公开事实 → 阈值判定 → 红旗 + 风险分 + 等级（不依赖模型，同输入同输出）
② 检索层  ai.py::_gather_search     18 路公开检索（8 基础 + 10 风控）→ 抓正文 → 编号引用
③ 模型层  ai.py::direct_bgcheck     只做定性补充与话术，**不得推翻规则层的数值判定**
                ↓
        报告 + 事实快照自动存档 → data/intelligence/<公司>/
```

**为什么要分三层**：模型会漏、会幻觉、会替企业说好话；数值类结论（实缴比例、参保人数、执行标的、案件数）用规则算才可复算、可审计、可复盘。模型只负责它擅长的部分：把零散材料串成因果、给出核实话术、判断"这个风险对我的具体影响"。

## 二、18 项风险维度（矩阵逐行覆盖）

| # | 维度 | 主要看点 |
|---|---|---|
| 1 | 空壳与实体真实性 | 集群注册/虚拟挂靠、无官网无案例、人员不到岗、只有招商招聘页 |
| 2 | 资本真实性与实缴 | 注册 vs 实缴差距、长期零实缴、减资、无形资产高评出资 |
| 3 | 股权、控制权与实控人 | 多层嵌套/代持、实控人失信、法人频繁更换（背锅法人） |
| 4 | **主体沿革与马甲史（换壳）** | 频繁更名、注册—运营—注销循环、吊销后新设同类主体 |
| 5 | 经营场所与地址真实性 | 注册地是否秘书公司集中注册、招聘地 ≠ 注册地 |
| 6 | 参保人数与用人规模真实性 | 参保 0 人 / 个位数 vs 宣称百人、参保逐年下降 |
| 7 | 涉诉总量与案由结构 | 单位年限涉诉密度、案由集中方向、是否被同一原告批量起诉 |
| 8 | 被执行、失信与限制高消费 | 被执行/失信/限高、终本案件、执行标的 vs 注册资本 |
| 9 | 合同与买卖纠纷 | 被供应商起诉索要货款（拖欠上游）、客户质量/退款纠纷 |
| 10 | 劳动争议、欠薪与用工合规 | 劳动争议趋势、欠薪黑名单、社保欠缴、克扣提成投诉 |
| 11 | 行政处罚与经营异常 | 经营异常是否移出、严重违法失信、处罚次数与类型 |
| 12 | 税务与发票合规 | 税务非正常户、欠税公告、重大税收违法失信 |
| 13 | 资金链与融资抵押 | 动产抵押/融资租赁、股权质押与冻结、对外担保链 |
| 14 | 破产、清算与注销风险 | 破产重整/和解/清算、吊销注销、债权人申请破产公告 |
| 15 | 舆情与雇主口碑 | 近一年负面新闻、员工评价（欠薪/克扣提成/不缴社保）、投诉主题 |
| 16 | 招聘真实性与骗局红线 | 押金/培训费/买产品、代理费加盟费、层级返利、外包伪装直招 |
| 17 | 资质牌照与行业监管 | 行业必需资质缺失/过期、超范围经营、环保/安全/数据合规 |
| 18 | 关联方与集团风险传导 | 母/兄弟公司失信被执行破产、互为担保、做烂一家换一家 |

## 三、规则层：52 个事实字段 → 红旗结论

**事实来源**：全部是你**手动从公开渠道抄写的数字**（不抓登录墙、不买号库、不绕过风控）。界面点「核查清单」会给出每个维度的检索关键词与 10 个官方查询入口。

| 组 | 字段（节选） |
|---|---|
| 主体与资本 | 注册资本、实缴资本、成立时间、经营状态、参保人数、宣称规模、注册地址性质、同地址企业数、曾用名次数、法人变更次数、关联/已注销企业数、官网、客户案例、中标记录 |
| 司法与执行 | 失信被执行人、被执行案件数与标的、限制高消费、司法案件总数、劳动争议数、合同纠纷数、借贷纠纷数、开庭公告数、股权冻结、实控人失信 |
| 经营与监管 | 经营异常及是否移出、严重违法失信、行政处罚次数、税务非正常户、欠税公告、破产程序、动产抵押数、股权质押、资质缺失 |
| 用工与舆情 | 欠薪黑名单、社保欠缴投诉、离职补偿争议数、强制加班投诉、工伤纠纷、重大负面新闻、投诉数与主题、雇主评分、岗位长期挂出 |
| 招聘与骗局红线 | 招聘收费、代理费/加盟费、层级返利、外包伪装直招、宣称国资背景、面试只谈缴费 |

**一票否决项（命中即判「红」，不给「可以放心入职」类结论）**

1. 被列为失信被执行人
2. 列入严重违法失信名单
3. 已进入破产重整/和解/清算
4. 主体状态为吊销/注销/清算/停业/迁出
5. 列入欠薪黑名单 / 重大劳动保障违法行为
6. 招聘环节收费（押金、培训费、买产品、服装费）
7. 以入职为条件收代理费/加盟费/保证金
8. 层级返利、拉人头（传销特征）

**评分与等级**：红旗按权重累计（一票否决 40 / 高 18 / 中 8 / 提示 3，封顶 100），一票否决项直接把分数压到 ≥75。

| 等级 | 分数 | 含义 |
|---|---|---|
| 绿 | ≤15 | 低风险：未见明显红旗，按常规核验 |
| 黄 | 16–40 | 中风险：逐条问清并要求书面确认 |
| 橙 | 41–70 | 高风险：多项红旗叠加，入职/签约前必须核实并要兜底条款 |
| 红 | >70 | 极高风险：命中一票否决或多条高风险，强烈建议放弃 |

**典型规则举例**（全部可复算）

| 条件 | 判定 |
|---|---|
| 注册 ≥1000 万且实缴 <5% | 高风险：撑门面/凑招投标门槛，实际可动用资金有限 |
| 成立 ≥3 年仍零实缴 | 高风险：股东未真实投入，赔付能力弱 |
| 执行标的 ≥ 注册资本 | 高风险：对外债务超出资本承受能力 |
| 参保 0 人 | 高风险：未开户/全员未缴/劳务用工，影响五险一金与工龄 |
| 参保 < 宣称规模 20% | 高风险：人数量级不符（夸大团队或大量外包） |
| 成立 <1 年 + 注册 <200 万 + 参保 ≤3 人 | 高风险：新壳三重叠加 |
| 空壳信号 ≥3 项叠加（集群注册/参保≤3/无官网/无案例/同址≥5家） | 高风险：实体经营真实性存疑 |
| 已注销关联企业 ≥3 家 | 高风险：做烂一家换一家的换壳模式 |
| 司法案件 ≥5 且年均 ≥2 件 | 高风险：履约/结算环节长期存在争议 |
| 合同纠纷 ≥5 / 借贷纠纷 ≥3 / 被执行 ≥3 / 劳动争议 ≥5 | 高风险：分别指向拖欠上游、资金链、强制执行、薪酬纠纷 |
| 曾用名 ≥2 次 | 中风险：需用旧名重查舆情与涉诉（负面常挂在旧名下） |
| 法人变更 ≥3 次 | 中风险：背锅法人/规避责任特征 |
| 动产抵押 ≥3 条 | 中风险：现金流偏紧、银行授信不足 |
| 宣称国资背景但股权无国资股东 | 高风险：冒用国资名义是招商/代理类骗局高频手法 |

## 四、检索与提示词

- **完整背调**：8 路基础检索 +（默认开启）10 路风控检索 → 16 章报告，第 13 节必须写成 **18 维度矩阵表** + 一票否决核查表 + 待核实清单
- **只做风险体检**（`mode=risk`）：12 路风控检索 → 六节结论（风险总评 / 18 维度矩阵 / 一票否决核查 / 求职视角 Top5 + 面试话术 / 待核实清单 / 决策建议），更快更省
- **风控关键词示例**：`X 被执行人 失信`、`X 劳动争议 劳动仲裁`、`X 欠薪 拖欠工资`、`X 员工 评价 克扣提成`、`X 注册地址 是否真实 办公`、`X 曾用名 更名记录`、`X 关联公司 注销`、`X 注册资本 实缴资本`、`X 招聘 押金 培训费 骗局`、`X 欠税公告 税务`、`X 破产 重整 清算`、`X 行政处罚`、`X 经营异常 严重违法失信`、`X 股权质押 动产抵押`、`X 投诉 维权`
- 规则层结论作为【本地规则层结论（确定性计算…不得推翻）】注入提示词，并要求：命中项必须原样出现在矩阵与一票否决表中

## 五、接口

| 接口 | 作用 |
|---|---|
| `POST /api/ai/direct/bgcheck` | 背调/风险体检：`mode=full\|risk`、`deep_risk`、`facts{}`（事实）+ `profile`（底线透镜）+ **`manual_material`（粘贴材料，填了就跳过搜索引擎）** |
| `POST /api/ai/direct/contact-map` | 触点地图七节（仅公开渠道） |
| `GET /api/risk/dimensions` | 18 维度目录 + 52 个事实字段元数据 + 官方入口（**前端表单由它生成**） |
| `POST /api/risk/evaluate` | 纯规则判定：事实 → 风险分/等级/红旗/缺失项（不调用模型，秒回） |
| `GET /api/risk/checklist?company=` | 核查清单：每维度检索关键词 + 官方查询入口 |
| `GET/POST/DELETE /api/archive/reports*` | 报告存档：列表 / 读取 / 删除 |

## 七、边界与合规

- **零额度方案**：界面上有「手工粘贴材料」折叠框；填入后完全跳过搜索引擎，仍走词库扫描 + 规则层 + 报告 + 存档。
  适合搜索额度用尽、或你已用 DeepSeek App / 官方公示系统查到内容时使用（材料未覆盖处照样写「材料未见」）
- **只用手填的公开事实 + 公开检索**：不抓登录墙平台、不绕过风控、不采集个人手机号（《个人信息保护法》+ 平台条款）
- 阈值是**启发式**经验值，不是法定标准：命中不等于违法，只代表"值得核实"；一票否决项（失信/破产/欠薪/收费）例外，属确定性负面事实
- 事实填得少 → 置信度低：界面会列出缺失的关键字段并提示去哪里查
- 涉诉、处罚、参保等强依赖公开数据覆盖度；查不到一律写「待核实」，不推测
- 报告是**决策辅助**，不构成法律意见；涉及劳动争议、合同纠纷请咨询专业人士
