# 模块 06 · 扩展中心（MCP 服务器 + 技能）

> 入口：侧边栏「扩展中心」/ `Ctrl+6` ｜ 前端 `frontend/src/views/ExtensionsView.tsx`、`lib/extensions.ts` ｜ 后端 `app/mcp_host.py`、`app/skills.py`

## 一、MCP 服务器（接入成熟外部模块）

### 逻辑

```
配置（data/config/mcp.json）
  { id, name, transport(stdio|http), command, args[], env{}, url, enabled, auto_approve, note }
      ↓ 测试连接 → 拉起/连接 → initialize → tools/list → 列出工具（带缓存 5 分钟）
      ↓ 汇总（GET /api/mcp/tools）→ 供 AI 助手的工具调用使用
      ↓ 调用（POST /api/mcp/call 或工具循环内部）→ tools/call → 返回文本内容
```

**两种传输**

| 传输 | 实现 | 适用 |
|---|---|---|
| `stdio` | 后端按 `command/args` 拉起子进程，用**自建 Popen + 线程 JSON-RPC 客户端**（不依赖 asyncio 子进程） | 大多数官方/社区 MCP 服务器（npx / uvx） |
| `http` | 官方 `mcp` SDK 的 streamable-http 客户端 | 你已在运行的服务（如远程/容器内） |

### 内置常用预设（一键添加）

| 预设 | 命令（示例） | 价值 |
|---|---|---|
| 文件系统 | `npx -y @modelcontextprotocol/server-filesystem <目录>` | 读写报告/知识库（可写，注意授权范围） |
| 网页抓取 Fetch | `npx -y @modelcontextprotocol/server-fetch` | 网页转 Markdown |
| SQLite | `npx -y @modelcontextprotocol/server-sqlite <db>` | 直接查询本地库 |
| Git | `npx -y @modelcontextprotocol/server-git --repository <dir>` | 知识库版本管理 |
| 长期记忆 Memory | `npx -y @modelcontextprotocol/server-memory` | 知识图谱记忆 |
| 结构化推理 | `npx -y @modelcontextprotocol/server-sequential-thinking` | 复杂分析拆解 |
| 浏览器自动化 | `npx -y @playwright/mcp@latest` | 可读需 JS 渲染的动态页 |

### 工程处理（踩过的坑）

| 问题 | 处理 |
|---|---|
| 受限环境拒绝 asyncio/anyio 子进程（`WinError 5`） | stdio 改为自建 `StdioRpc`（Popen + 线程 + 换行 JSON-RPC） |
| Windows 上 `npx` 是 `.cmd`，CreateProcess 不补扩展名 | `_resolve_command()` 解析为绝对路径 |
| npx 默认把缓存/日志写进用户目录（被拒 + 污染系统） | 注入 `--cache <项目>/data/cache/npm` 并设 `npm_config_cache` |
| MCP SDK v2 HTTP 函数改名 | 兼容 `streamable_http_client` 与 `streamablehttp_client` |

### 存储

| 数据 | 位置 |
|---|---|
| 服务器配置 | `data/config/mcp.json` |
| 依赖包与缓存 | `data/cache/npm/`（随项目迁移） |
| 工具清单缓存 | 后端内存（5 分钟 TTL，重启即清） |

### 安全建议

- 第三方 MCP 服务器 = **在本机运行他人代码**；默认不自动批准 → 高风险操作需你确认
- 文件系统类预设请把路径限定到必要的目录（默认已限定项目根）
- 不用时把 `enabled` 关掉即可，配置与工具不会被调用

## 二、技能（Skills）

### 逻辑

```
存储：data/skills/<name>/SKILL.md
  front-matter（可选）：title / description
  正文 = 注入模型的指令（渐进式：只在调用时注入，省 token）
      ↓ 调用（POST /api/skills/{name}/run）：用选中的直连模型执行
      · system = 技能正文 + 通用要求（中文 / 不编造 / 缺失标待补充 / Markdown）
      · user   = 输入 + 可选补充材料
      ↓ 结果以 Markdown 面板展示，可下载
```

### 内置 4 个技能（首次运行自动生成）

| 技能名 | 标题 | 用途 |
|---|---|---|
| `jd-breakdown` | JD 拆解 | 硬性门槛 / 真实职责 / 考核口径 / 隐藏信息 / 面试必问 8 题 |
| `resume-tailor` | 简历定向润色 | 匹配度自评 + 按 JD 重写要点 + 该删什么 + 缺口补强 |
| `interview-drill` | 面试出题与追问 | 12 题清单 + STAR 追问链 + 答法骨架 |
| `intel-brief` | 情报摘要与风险标记 | 表格化简报 + 可信度 + 待核实 + 下一步动作 |

### 接口

| 接口 | 作用 |
|---|---|
| `GET /api/skills` | 技能列表（title/description/字数/更新时间） |
| `GET /api/skills/{name}` | 读取 SKILL.md 原文 |
| `POST /api/skills` | 新建 / 保存（body: `{name, content}`） |
| `DELETE /api/skills/{name}` | 删除 |
| `POST /api/skills/{name}/run` | 按技能执行（`provider_id, input, context`） |
| `POST /api/skills/import` | 从 URL 导入公开 SKILL.md（如 GitHub raw） |

### 存储

| 数据 | 位置 |
|---|---|
| 技能指令包 | `data/skills/<name>/SKILL.md`（每技能一个目录，可加脚本/模板） |
| 试运行结果 | 界面展示，可下载 |

## 三、把 MCP 当成"搜索引擎"用（本轮新增，重要）

**默认行为**：MCP 工具只被「AI 助手」调用（开启「允许调用工具」后由模型自主决定），**雷达/背调流水线不走 MCP**。

**新增桥接**：设置 → 搜索引擎选择 **「MCP 检索工具」**，填三样东西即可让任意 MCP 检索工具**驱动雷达/背调/行业研判**：

| 字段 | 说明 |
|---|---|
| MCP 服务器 id | 扩展中心里配置的服务器 id（如 `searxng`） |
| 检索工具名 | 该服务器暴露的检索工具（如 `search` / `web_search`） |
| 查询参数名 | 工具要求的参数名（`query` / `q` / `keyword`） |

调用链：`_search_engine(engine="mcp")` → `call_tool_direct(server_id, tool, {arg: query, max_results: n})`
→ `_parse_mcp_search_text()` 解析返回文本（支持 Markdown 链接 `[标题](url)`、`标题｜url`、裸 URL 三种形态）
→ 结果进入正常的抓正文 / 词库扫描 / 评分流程。解析不到链接会明确报错（并提示用 `/api/mcp/call` 看原始返回），不臆造结果。

## 四、MCP 选型建议（与检索能力相关的实测结论）

前提：**免 Key 的 DuckDuckGo 已内建为搜索引擎**（`ddgs` 包，实测国内可用、2 秒出结果），所以"单纯为了免费搜索"不必再装 MCP。
MCP 更适合补**专项数据**：

| 用途 | 推荐 | 价值 | 备注 |
|---|---|---|---|
| 免 Key 网页检索 | [mcp-server-freesearch](https://github.com/wzj177/mcp-server-freesearch)、[agent-search](https://github.com/brcrusoe72/agent-search)（自带 SearXNG，一条命令） | ⭐⭐⭐ | 需自建实例（公共 SearXNG 实例本机网络全部超时）；自建后可按上文桥接成引擎 |
| 免 Key 检索（轻量） | [duckduckgo-mcp](https://pypi.org/project/duckduckgo-mcp/)、[duckduckgo-mcp-agent](https://github.com/cploutarchou/duckduckgo-mcp-agent) | ⭐ | 与内建 `ddg` 能力重复，可跳过 |
| 招聘数据 | [jobspy-mcp-server](https://github.com/chinpeerapat/jobspy-mcp-server) | ⭐ | 只覆盖 LinkedIn / Indeed / Glassdoor / Google Jobs，**不含 BOSS/智联/猎聘**，且需代理 |
| 上市公司财务 | [akshare-one-mcp](https://pypi.org/project/akshare-one-mcp/)、[china-stock-mcp](https://pypi.org/project/china-stock-mcp/) | ⭐⭐ | A股/港股行情财报，做**上市公司背调**（营收/毛利/现金流）很实用 |
| 文件与知识库 | 官方 `server-filesystem` / `server-fetch` / `server-sqlite` / `server-memory` / `server-sequential-thinking` | ⭐⭐ | 扩展中心已内置预设，报告落盘与知识库检索够用 |
| 国内工商/司法 | ⚠️ 没有成熟开源 MCP | — | 企查查/天眼查只有付费 API；用「手工粘贴材料」把公示系统/裁判文书网查到的内容喂进来 |

**明确不建议**：任何宣称"绕过登录墙/验证码""批量导出招聘简历与手机号"的 MCP——违反平台条款与《个人信息保护法》，本项目一律不采集个人手机号。
