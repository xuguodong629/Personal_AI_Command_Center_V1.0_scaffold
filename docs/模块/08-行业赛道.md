# 模块 08 · 行业赛道（生命周期五档研判）

> 入口：侧边栏「行业赛道」/ `Ctrl+2` ｜ 前端 `frontend/src/views/IndustryView.tsx` ｜ 后端 `backend/app/industry.py`、`ai.py`（`/ai/direct/industry`）

## 一、为什么要单独一个视图（关于"是否单独模块"的结论）

**结论：值得单独成视图，但引擎必须共享。**

| 理由 | 说明 |
|---|---|
| 输入维度不同 | 雷达输入是「岗位×区域×行业」，背调输入是「公司」，赛道研判输入是「行业+区域」，混在雷达里会让一个表单承担三种语义 |
| 结论要长期跟踪 | 行业的生命周期会迁移（今天的蓝海两年后就是红海），需要**按行业存档、按时间对比档位变化** |
| 结论被多处复用 | 雷达（选哪个行业投）、深度分析（VC 第一步赛道判断）、背调（行业地位）都要用同一套判定，**不能各写一套** |
| 但不宜再碎片化 | 所以只做「一个视图 + 一个引擎」：`industry.py` 供所有模块调用，视图只负责输入、展示与存档 |

**不单独建模块的替代方案**（如果你想要更轻）：把它折叠进岗位雷达作为一张表。但那会导致"行业结论"每次都要和岗位检索一起重跑（贵且慢），也无法做长期跟踪——因此我选了独立视图 + 共享引擎。

## 二、五档定义（判据 + 对求职的含义）

| 档位 | 分数 | 特征 | 对你的机会 | 风险 | 进入结论 |
|---|---|---|---|---|---|
| **新势力 / 风口期** | ≥80（且过门槛） | 技术或政策驱动新需求；格局未定；资本密集；标准与渠道未形成 | 早期参与可拿股权/期权，能力稀缺溢价高 | 现金流不稳、融资断档即裁员；常是"从零开荒无资源" | 可进，但按风投标准（小额、短周期、可撤出） |
| **蓝海朝阳（成长期）** | 65–79 | 需求快速增长、渗透率抬升；玩家增加但格局初定；政策扶持；毛利尚可 | **体系搭建期**：渠道政策/区域架构还在建，区域负责人价值与谈判空间最大 | 扩张过快、管理粗放；补贴依赖 | **最佳窗口：优先投递** |
| **平稳存量（成熟期）** | 45–64 | 增速与 GDP/人口同步；集中度较高；以旧换新/替换需求为主 | 体系成熟、现金流稳、五险一金规范，适合"成熟体系放大器" | 晋升拥挤；增量靠抢份额，指标逐年加码 | 稳健选择：**只进龙头或细分第一** |
| **红海内卷（饱和期）** | 25–44 | 增速低或负；玩家众多；价格战与同质化；毛利下滑；靠输血维持 | 只剩效率与成本优势 | 压货与拖欠高发；提成规则常被单方面调整 | 谨慎：除非头部+条件书面化，否则不进 |
| **夕阳没落（衰退期）** | <25 | 需求持续萎缩；政策限制或替代技术成熟；产能过剩、批量退出 | 少数垄断细分仍稳定 | 裁员与欠薪风险最高；技能随行业贬值 | 不建议：优先做行业迁移 |

**新势力门槛（防止"增长快"被误判成风口）**：只有满足其一才算风口——
① 需求信号＝爆发；② 增速 ≥30% 且近 12 个月融资 ≥15 起；③ 玩家大量增加且需求爆发。
否则即使分数 ≥80 也压回「蓝海朝阳」（输出里会写明这条门槛）。

## 三、规则层：17 个事实字段 → 加权算分

| 字段 | 权重 | 取值与得分 |
|---|---|---|
| 需求信号 | 25 | 爆发 1.0 / 快速增长 0.85 / 稳定 0.55 / 放缓 0.3 / 萎缩 0.05 |
| 行业规模近 3 年复合增速 | 15 | ≥30% 1.0 / ≥15% 0.85 / ≥5% 0.6 / ≥0 0.45 / 负增长 0.1 |
| 政策方向 | 12 | 强扶持 1.0 / 扶持 0.8 / 中性 0.55 / 限制 0.25 / 强限制 0.05 |
| 价格战/内卷程度 | 12 | 无 1.0 / 局部 0.7 / 激烈 0.35 / 恶性 0.1 |
| 毛利率趋势 | 10 | 上升 1.0 / 持平 0.6 / 下降 0.3 / 大幅下降 0.1 |
| 融资/并购事件数 | 10 | ≥20 起 1.0 / ≥10 0.85 / ≥5 0.7 / ≥1 0.5 / 0 0.35 |
| 产能/供给 | 6 | 严重不足 0.9 / 偏紧 0.85 / 平衡 0.6 / 过剩 0.3 / 严重过剩 0.1 |
| 玩家数量变化 | 6 | 大量增加 0.9 / 缓慢增加 0.75 / 稳定 0.55 / 开始减少 0.4 / 大量退出 0.15 |
| 招聘需求趋势 | 6 | 大幅扩张 1.0 / 扩张 0.85 / 平稳 0.55 / 收缩 0.3 / 大幅收缩 0.1 |
| 上市/过会企业数 | 5 | ≥5 家 1.0 / ≥1 0.75 / 0 0.5 |
| 补贴或资本依赖 | 5 | 否 0.9 / 是 0.3 |
| 薪资趋势 | 4 | 上涨 0.9 / 持平 0.6 / 下降 0.3 |
| 技术替代威胁 | 4 | 弱 0.8 / 中 0.6 / 强 0.35 |
| 出口出海 | 4 | 高增长 0.9 / 平稳 0.6 / 下滑 0.3 |
| 当地产业基础 | 4 | 强 0.85 / 中 0.6 / 弱 0.35 |
| 集中度 CR5 / 关键政策 | — | 记录展示，参与人工判断 |

**硬性上限（可解释、防误判）**

| 条件 | 结果 |
|---|---|
| 政策＝强限制 | 上限「红海内卷」 |
| 恶性价格战 + 毛利下滑 | 上限「红海内卷」 |
| 产能过剩 + 需求放缓/萎缩 | 上限「红海内卷」 |
| 需求萎缩且规模负增长 | 上限「夕阳没落」 |
| 需求放缓/萎缩 + 招聘收缩 | 上限「平稳存量」 |

## 四、词库层：阶段特征词交叉验证

从检索材料里数各档特征词，与规则层档位互证：

| 档位 | 特征词（节选） |
|---|---|
| 新势力 | 元年、爆发、颠覆、首发、试点、独角兽、新赛道、资本追捧、技术突破、风口 |
| 蓝海朝阳 | 快速增长、渗透率提升、政策扶持、扩容、需求旺盛、供不应求、涨价、抢跑 |
| 平稳存量 | 存量、以旧换新、更新换代、稳定增长、成熟期、份额、龙头集中、替换需求 |
| 红海内卷 | 价格战、内卷、杀价、降价、同质化、亏损、补贴退坡、产能过剩、库存高企、价格倒挂 |
| 夕阳没落 | 需求萎缩、退出、关停、去产能、限制、下滑、转型、裁员、停产、衰退 |

材料语言与规则层档位冲突时，**以规则层为准**，并在报告中指出"补哪个字段可以修正判定"。

## 五、检索与提示词

- **8 路检索**：`{行业} 行业 市场规模 增速 报告`、`融资 事件`、`价格战 内卷 降价 毛利率`、`产能过剩 供大于求 库存`、`政策 规划 支持 限制 标准`、`龙头 市占率 集中度 CR5`、`招聘 人才 需求 薪资 趋势`、`{区域} {行业} 产业 集群 基础 配套`
- **五节报告**：① 赛道判定（档位+分数+交叉验证）② 需求与增速 ③ 竞争格局与集中度 ④ 政策与产业链（哪份文件/哪一级/支持什么）⑤ 进入时机与个人动作（投递优先级 / 选什么岗 / 谈薪与避坑 / 先核实哪 3 件事）
- 第五节**必须结合候选人画像**：定位"成熟体系放大器"时 → 蓝海朝阳/平稳存量最优、龙头优先；新势力按风投标准核实现金与融资节奏；红海必须核实提成兑现与账期；夕阳给迁移路径
- 规则层档位作为【本地规则层赛道判定】注入，要求第一节原样呈现，**不得推翻**

## 六、接口

| 接口 | 作用 |
|---|---|
| `GET /api/industry/framework` | 五档定义 + 17 个字段元数据 + 特征词库 + 权重表（前端表单由此生成） |
| `POST /api/industry/evaluate` | 纯规则判定（秒回、不花模型钱） |
| `GET /api/industry/checklist?industry=&region=` | 核查清单：8 条检索关键词 + 五档判据 |
| `POST /api/ai/direct/industry` | 完整研判：8 路检索 + 规则层 + 词库层 + 模型五节报告 + 自动存档 |

## 七、数据存储

| 数据 | 位置 |
|---|---|
| 行业事实（界面状态） | 浏览器 localStorage `jc-industry-facts`、`jc-industry-inputs` |
| 研判报告 | `data/knowledge/_行业/<行业名>/<YYYY-MM-DD-HHMM>-行业赛道研判.md`（front-matter 含档位与分数） |
| 事实快照 | 同目录 `<同名>-facts.json`（用于对比不同时间的档位变化） |

> 与 `data/intelligence/`（公司档案）分开存放：行业认知属于长期知识库，公司情报属于对象档案。

## 八、边界与已知限制

- 规则层是**启发式加权**，不是权威评级；它给的是"该用哪套策略"的档位，不是精确结论
- 行业规模/增速等数据必须来自公开报告（国家统计局、行业协会、券商研报、上市公司年报）；填不出来的字段留空，界面会列出缺失项并降低置信度
- 同一行业在不同区域可能处在不同档位（区域产业基础已作为字段参与评分），所以研判要带区域视角
- 与雷达联动：雷达结果页「下一步：行业赛道研判」会把当前目标行业/区域带过去
