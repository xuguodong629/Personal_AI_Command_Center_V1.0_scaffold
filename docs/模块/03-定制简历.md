# 模块 03 · 定制简历

> 入口：侧边栏「定制简历」/ `Ctrl+3` ｜ 前端 `frontend/src/views/ResumeView.tsx` ｜ 后端 `backend/app/ai.py`

## 一、功能逻辑

```
输入：岗位 JD（可从机会池复制，或一键「从剪贴板粘贴」）
      ＋ 简历 JSON/摘要（留空则自动使用 public/config/local-defaults.json 的简历摘要）
      ↓ 单次模型调用（无需联网搜索，纯推理）
输出四段：
  # 六维匹配分析
     行业经验 / 能力技能 / 业绩成果 / 管理与跨度 / 地域与稳定性 / 发展意愿匹配
     （Markdown 表格：维度 | 匹配度 高·中·低 | 依据）
  # 岗位核心要求解读
     提炼 ≤5 条真正决定成败的要求
  # 定制简历（一岗一版）
     按目标岗位重写：突出匹配经历与量化成果，弱化无关内容，控制在一页纸；
     句式统一为「动作 + 场景 + 量化结果」
  # 面试风险与准备建议
     3–5 个面试官最可能挑战的点 + 应对建议
```

## 二、接口

| 接口 | 作用 |
|---|---|
| `POST /api/ai/direct/resume` | 入参 `provider_id / job_description / resume_text` → 返回定制简历与分析 |

提示词要点（`RESUME_SYSTEM`）：资深猎头 + 简历优化专家；熟悉家电、消费品、制造业与 B2B 行业招聘逻辑；输出中文 Markdown、信息密度高、不写客套话；**不得臆造候选人没有的经历**，缺失信息标注待补。

## 三、数据存储

| 数据 | 位置 |
|---|---|
| JD 输入 | localStorage（`jc-resume-jd`） |
| 简历 JSON/摘要输入 | localStorage（`jc-resume-json`） |
| 本地默认简历 | `frontend/public/config/local-defaults.json`（不入 git） |
| 生成结果 | 组件状态 + 可「下载」为 Markdown |

## 四、使用建议

- **先跑岗位雷达拿机会池 → 把目标岗位 JD 粘进来**，比手工找 JD 更贴目标
- 简历留空时用的是 `local-defaults.json` 里的画像与简历摘要（改那个文件即可全局生效）
- 若要长期管理多版简历，规划中的 `data/knowledge/`（Markdown 知识库）会承载「一岗一版」的版本留档
