# 模块 05 · AI 助手

> 入口：侧边栏「AI 助手」/ `Ctrl+4` ｜ 前端 `frontend/src/views/ChatView.tsx` ｜ 后端 `app/ai.py`

## 一、功能逻辑

```
模式 A：普通对话（默认）
  选中模型 → POST /api/ai/chat（messages 数组）
  历史保留最近 60 条（localStorage），Markdown 渲染，可选模型即时切换

模式 B：允许调用工具（勾选后）
  → POST /api/ai/chat-tools
     1) 汇总所有已启用 MCP 服务器的工具（转成 OpenAI function schema）
     2) 模型自行决定是否调用；命中则执行工具并把结果回填，最多 3 轮
     3) 返回最终回答 + 调用轨迹（工具名 / 参数 / 结果片段）
     4) 若没有任何可用工具 → 自动退化为普通对话，不报错
  界面在回答下方展开「本次调用了 N 个工具」面板，便于审计
```

## 二、接口

| 接口 | 入参 | 说明 |
|---|---|---|
| `POST /api/ai/chat` | `provider_id, messages[]` | 单轮对话（无工具） |
| `POST /api/ai/chat-tools` | `provider_id, messages[], server_ids?, max_rounds?, system?` | 工具调用循环；`server_ids` 为空 = 所有已启用服务器 |

返回：`{ ok, content, trace[], tool_errors[], model }`

## 三、数据存储

| 数据 | 位置 |
|---|---|
| 对话历史 | 浏览器 localStorage（`jc-chat-history`，上限 60 条） |
| 当前模型选择 | localStorage（`jc-chat-provider`） |
| 「允许调用工具」开关 | localStorage（`jc-chat-tools`） |
| 工具调用的真实执行 | 由 MCP 服务器在自己进程/目录中完成（配置见 `data/config/mcp.json`） |

> 若要把某些对话长期留档：可复制到知识库（规划中的 `data/knowledge/`），或存为技能（`data/skills/`）。

## 四、依赖与前提

- 至少配置一个 OpenAI 兼容模型（设置 → 模型直连）
- 用「允许调用工具」前，先在**扩展中心**添加并启用 MCP 服务器
- 模型需支持 function calling（DeepSeek、GLM 均支持）；不支持时会把工具说明书当普通文本，效果下降

## 五、边界

- 工具调用有轮数上限（默认 3，最大 5），防止无限循环
- 高风险工具（写文件、执行命令）会真实执行：MCP 服务器的「免确认」开关请谨慎开启
- 对话上下文只保留最近 60 条，超长材料建议走「技能」或专用模块（雷达/背调）
