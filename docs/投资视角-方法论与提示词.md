# 投资视角 · 选企业与潜力企业方法论（求职 = 重仓投资）

> 核心前提：**求职 = 一笔重仓风险投资**——投入的是每天 8 小时+ 的黄金年华，公司给的是「现金 + 成长权」。投资人怎么选企业，你就怎么选雇主；投资人怎么找潜力股，你就怎么找潜力企业。
> 集成位置：岗位雷达机会池生成后，两个并列的深度分析按钮：
> - 「投资视角 · 潜力企业深挖」→ 后端 `/api/ai/direct/deep`（mode=invest，即本文五步）
> - 「优秀企业筛选（6 步）」→ 同端点 mode=screen（画像校准→目标企业画像→8 维筛选→加权打分表→避坑清单→决策建议，模板见 backend/app/ai.py `_screen_user`）
> 分析材料 = 雷达机会池 + `local-defaults.json` 候选人画像。

## 一、世界级投资人的逻辑 → 求职版翻译

| 投资人/机构 | 原逻辑 | 求职版含义 |
|---|---|---|
| 巴菲特/芒格 | 护城河、能力圈；"用合理的价格买伟大的公司…"；管理层诚信 | 选「渠道护城河深（品牌力/独占网点）+ 老板诚信」的公司；宁可薪资略低进成长体系，别为多 2 千进烂体系 |
| 芒格（逆向） | "反过来想，总是反过来想" | 先做**减法**：用底线清单（拖欠费用/压货考核/无体系）直接否决，剩下的再谈好坏 |
| 段永平 3R | Right Business → Right People → Right Price | ① 生意模式：渠道层级利润分配是否健康；② 老板/上级是否"本分、诚信、懂行"——先人后事；③ 价格：薪资+成长是否匹配 5000 万级能力 |
| 红杉/风投界 | 团队（赛手）执行力是最大风险 | 面试优先评估直属领导和老板；管理混乱的公司业务再好也难有你的空间 |
| 孙正义 时光机 | 把已验证市场的成熟模式搬到落后市场 | **潜力企业识别核心**：找「一二线已验证、正在河南/县域加速复制」的品类与品牌 |
| 张磊 高瓴 | 长期主义；"弱水三千，只取一瓢" | 守能力圈（家电/渠道），选能干 3–5 年、能升到省区/总监级的长期盘 |
| 雷军 | 顺势而为 | 看宏观势能：家电下乡、以旧换新、县域消费升级——趋势向上的行业才有超额回报 |

## 二、风投评估指标 → 求职尽调指标

| 风投指标 | 风投标准 | 求职版尽调问题 |
|---|---|---|
| 市场大小 TAM | $100M+ 潜力 | 该品类在河南盘子多大？能操盘多少？（>3000 万为佳） |
| Traction 增长验证 | A 轮 100%+ YoY | 公司近两年营收/门店数/代理商数扩张还是平台期？ |
| 团队 | 创始人有产业背景、互补 | 老板/直属上级：诚信、放权、带出过人？ |
| 单位经济模型 | LTV:CAC>3:1 | 经销商单店盈利模型是否跑得通？返利/账期健康？（经销商不赚钱，体系必崩） |
| 资本效率/现金流 | 结算周期 | 费用结算及时？有无拖欠？（红线，直接否决） |

红色信号对照：岗位挂半年还在招（=死项目流动性高）；压货冲量式增长（=刷单式假增长）；老板一人拍板无体系（=单打独斗执行风险最高）。

## 三、仓位策略（80/20）

| 仓位 | 类型 | 对应轮次 | 打法 |
|---|---|---|---|
| 主力 80% | 成熟体系 + 扩张期（大品牌新品类线、上市公司第二曲线、被收购后规范化品牌） | A/B 轮型 | 直接投递/内推，用"5000 万级放大能力"换确定性 |
| 机会 20% | 河南本地品牌正在规范化（创始人愿给资源、有产业背景） | 天使轮型 | 小步试探；核实是否愿给资源建体系，否则=空壳否决 |

> 一句话：用巴菲特的方式选主力（伟大的生意 + 对的人），用孙正义的时光机找潜力（正在复制到河南的成熟模式）。

## 四、集成后的五步执行结构（后端 /api/ai/direct/invest）

1. **赛道判断**（顺势而为 + 时光机）：河南家电/厨电/耐消中「一二线已验证、正在河南/县域加速复制」的品类，按投资价值排序
2. **潜力企业清单**（80/20）：主力型 / 机会型各家 + 潜力股理由 + 增长信号 + 风险
3. **五张尽调卡**：市场 / 增长验证 / 团队 / 单位经济模型 / 现金流
4. **逆向否决 + 价值判断**：底线做减法 → "值得 3–5 年买入持有吗"
5. **决策输出**：重仓买入 / 观察仓 / 直接卖出 三层名单 + 投递路径 + 3 个验证信号

材料不足的维度统一「待验证」并给查证动作，不编造数字。
