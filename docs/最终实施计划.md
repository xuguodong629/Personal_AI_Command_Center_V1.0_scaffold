## 二、总体策略

1. **不推倒重来**：保留 V0.1 设计语言，按规格重构为模块化工程（UI ≠ 业务 ≠ AI ≠ 数据库，规格 §39）。
2. **自建差异化核心**：驾驶舱、审核中心、决策中心、模块系统、收件箱流程；**复用成熟轮子**：知识格式用标准 Markdown（借鉴 SiYuan 思路）、模型协议用 OpenAI 兼容、自动化后期可接 n8n 思路。
3. **四档模型分工**：本地优先 + 按需上云（规格 §31 模型路由）。

## 五、分阶段计划

### P0 环境确认（token 1–2万）

- **做什么**：工具链就位 + 现有工程可运行性确认
- **怎么做**：
  1. `node -v`、`npm -v`（需 ≥20）
  2. `python --version`（需 3.11+）
  3. `ollama list` 确认 qwen3.5-4b；`curl http://localhost:11434/v1/models` 确认服务
  4. platform.deepseek.com 充值 ≥10 元，创建 API key
  5. 跑通现有工程：前端 `cd frontend && npm run dev`（127.0.0.1:5173）；后端 `cd backend && python -m venv .venv && .venv\Scripts\activate && pip install -r requirements.txt && uvicorn app.main:app --port 8787`
- **用什么做**：你在本机执行，结果贴回本环境核对
- **验收**：两端都能跑，`/api/health` 返回 online

### P1 工程重构 + 中文 UI + Tauri 壳（token 6–10万）

- **做什么**：单文件拆分为工程结构；界面全面中文化；14 模块导航；Tauri 壳
- **怎么做**（本环境产出代码）：
  1. 拆分 frontend/src：`App.tsx` / `main.tsx` / `pages/`（14 页占位）/ `components/`（模块导航.tsx、指标卡.tsx、AI指令栏.tsx…）/ `store/`（模块状态.ts、主题状态.ts、系统状态.ts）/ `styles/`（global.css、layout.css、themes.css）
  2. 导航对齐规格 14 模块：首页、AI 对话、收件箱、知识库、情报中心、工作中心、项目中心、学习中心、决策中心、审核中心、AI 分析中心、数据中心、自动化中心、系统设置（保留 ⌘K 命令面板）
  3. 页面切换用 Zustand（不引入 react-router，桌面应用无需 URL 路由）
  4. 新增 `src-tauri/`（Cargo.toml、tauri.conf.json、src/main.rs）
  5. 你执行：`npm install` → `npm run tauri dev`（首次 Rust 编译 5–15 分钟，配 rsproxy 镜像）
- **用什么做**：代码 = 本环境；命令 = 你；Rust 报错 = 贴回本环境，顽固的转 Claude 网页版
- **验收**：Tauri 窗口显示中文「个人 AI 指挥中心」，14 模块可切换

### P2 主题引擎（token 3–5万）

- **怎么做**：themes/ 下 6 个主题 token 文件（CSS 变量：深空指挥中心 / 未来操作系统 / 高级数据驾驶舱 / AI神经网络 / 赛博数据中心 / 极简未来）+ themes.css + 主题状态 store + 系统设置切换器 + 模块→主题映射表（规格 §24）
- **用什么做**：本环境写；你跑 dev 验证
- **验收**：一键切换 6 套主题，全局换肤

### P3 首页驾驶舱（token 3–5万）

- **验收**：符合规格 §5 布局

### P4 模块系统 + 系统设置（token 3–6万）

- **做什么**：模块增删隐藏排序 + 数据目录配置
- **怎么做**：模块状态 store（持久化到 data/config/modules.json）；系统设置.tsx 提供增删隐藏排序、数据目录选择、主题选择；后端 /api/config 扩展

### P5 双引擎 AI 接入（token 3–5万）

- **做什么**：本地 Qwen + DeepSeek 双引擎路由
- **怎么做**：
  1. `backend/ai/router.py`：OpenAI 兼容协议，双 base_url 配置

  3. 简单任务路由本地、复杂任务路由 API；JSON 输出约束 + 置信度阈值
  4. AI 指令栏接通后端 `/api/ai/chat`
- **验收**：指令栏「你好」走本地 Qwen；切配置走 DeepSeek

### P12 决策中心（token 5–8万）

- **怎么做**：决策模板（规格 §14 全字段）+ 决策中心.tsx；AI 生成方案对比（DeepSeek）

## 七、执行纪律

1. 阶段验收制：每阶段验收通过才进下一阶段；工程 01 验收点是硬门槛。
2. 报错贴完整原文 + 相关文件，一次修一批。
3. 攻坚轮换：大块 → Claude 网页；小块 / 查资料 → ChatGPT 网页；被限流换人。
4. 数据目录固定：data/{config, database, inbox, knowledge, intelligence, projects, logs}。
5. 原始数据永不直接覆盖（规格 §30）：原始版 + 修改版 + 审核记录。
6. AI 不直接删改核心数据：只建议，人工批准后才执行（规格 §3.4）。

### "用 DeepSeek API 做检索"可行性核实 + 手工粘贴材料模式（本轮）✅

**问题**：搜索额度用尽后，用户问"用 DeepSeek 的 API 怎么样"。

**核实结论：DeepSeek API 不能做检索，只能做模型。** 官方文档 + 用用户自己的 Key 实测，四条证据一致：

| 探测 | 结果 |
|---|---|
| `POST /chat/completions` + `tools=[{"type":"web_search"}]` | **HTTP 422**：`tools[0].type: unknown variant 'web_search', expected 'function'` |
| `POST /responses` + 同款内置工具 | HTTP 200，但响应中**无 `web_search_call`、无 url 字段**；模型自述"我们作为模型无法直接实时浏览" |
| `POST /web_search` / `/search` / `/v1/web_search` | **全部 404**（无独立搜索端点） |
| 官方文档《使用 Responses API》Tools 表 | `web_search / file_search / code_interpreter / computer_use / mcp` 等内置工具 → **忽略** |

DeepSeek 的联网搜索只存在于它的 App/网页版产品里，**不对外开 API**。所以正确组合是：**模型用 DeepSeek（便宜、中文强）+ 检索另配引擎**。

**新增：手工粘贴材料模式（零额度路径，实测可用）**

## 关于「给反爬加逆向」：不做，改用合规手段把材料做厚（2026-09-21 续）

**结论：不做逆向抓取。** 三条理由：
1. **与本项目自定红线冲突**（`docs/模块/01-岗位雷达.md` 第八节：「不做逆向爬虫：不绕过登录墙、验证码与站点风控」）。
2. **法律与协议风险**：绕过技术保护措施涉及《网络安全法》《数据安全法》与平台用户协议；且这类手段在司法实践中已被反复认定为不正当竞争。
3. **工程上也不划算**：智联是风控校验页（`Security Verification`）、51job 是统一拦截页、BOSS 是 JS+风控。要稳定绕过需要打码、浏览器指纹伪造、代理/IP 池、账号池——成本高、随时失效，而且**你自己的 IP 与账号（你还得用这些 App 找工作）会被封**。

**改用合规替代（本轮已实现并实测）**

| 手段 | 效果（实测） |
|---|---|
| 四大招聘站**岗位页定向**（`site:` 运算符） | 召回直接落在岗位页，不再全是公司页/校招页 |
| **官方社招页定向**（品牌 → 官方招聘域名，按批次轮换 15 家） | 海尔官方社招岗位直接进材料并进池（优先投递 82–90 分） |
| 登录墙改**按 URL 类型**判定 | 猎聘移动岗位页正文 2596 字 / JD 词 10-10 命中，12 条岗位页不再被整片跳过 |
| **检索摘要即 JD 证据** | 51job/智联/BOSS 摘要里带「岗位职责/核心工作职责」原文；修复抽取器（正文与摘要取更完整者），大量"JD 缺失"行转为可用 |
| 第三方 ATS（`hotjob.cn` 北森大易） | 正文可抓（959–3338 字含 JD），已加入定向与抓取优先级；Moka 未索引岗位页，暂不投入 |
| **确定性岗位候选清单 + 池子兜底** | 池子不再依赖模型抄写；`invalid` 不灌进待核实；同岗位按 URL 归一化去重 |
| 手工粘贴材料模式 | 零风险、零额度的兜底路径，永远可用 |

**验收（真实 DeepSeek + serper，20 路）**：池 16 条（`deterministic_merged` 9）｜待核实 15 ｜排除 4｜
前排为海尔官方社招河南渠道岗（信阳区域销售经理 82、郑州网格销售 75、开封商空销售经理 75）｜假岗位硬检查 3 项 PASS｜
`selfcheck_jobs.py` 62 项全通过。

**如果要继续加厚材料，合规的三条路（需要你选）**
1. **官方 API / 授权数据**：BOSS/智联/猎聘的企业版接口，或第三方持牌数据服务商（花钱、合法、稳定）→ 我可以接进设置页。

3. **粘贴模式做成一键结构化**：你从 App 复制 JD，程序切成候选清单直接判定，10 条约 1 分钟，零风险。
